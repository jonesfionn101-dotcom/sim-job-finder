# Sim Job Finder

Automatic searches that run on GitHub Actions (no PC needed) and post their results as issues in this repo:

- **Job shortlist**: fresh open-source issues in JS/TS projects that take outside contributions, allow AI help, have a live Discord and can be tested.
- **Rules job search**: recruiting UK truck-sim VTCs (via Trucky), checked for a website, a live Discord, staff numbers and recent activity.
- **App project search**: open-source tracker, food, delivery and truck-sim apps with open issues.
- **Community search**: farming-sim (FS22), transport, other sim and UK/Irish gaming communities from Discord's public server directory.
- **Draft a fix**: once a day, GitHub's free AI models try one fix and prove it with the project's own tests. A passing fix is saved as a "needs check" issue for review. Nothing is ever sent automatically.
- **Search recorder**: a pinned issue that logs every run starting and finishing.

All searches are read-only: nothing is joined, posted or contacted.
